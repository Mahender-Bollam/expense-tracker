# Expense Tracker App

A simple and interactive Expense Tracker built with **React + TypeScript**.  
This app allows users to **add, edit, and delete expenses**, categorize them, and track spending easily.

---

## Features

- Add new expenses with description, amount, category, and date.
- Edit existing expenses.
- Delete expenses.
- Categorize expenses (e.g., Food, Travel, Shopping). 
- View total expenses summary.

## Installation & Setup

### Clone the repository
```bash
git clone https://github.com/Mahender-Bollam/expense-tracker
cd expense-tracker
````

### Install dependencies

```bash
npm install
```

### Run the app

```bash
npm start
```

The app will open in your browser at **[http://localhost:3000](http://localhost:3000)** 

---

## Run Tests

To execute all Jest test cases:

```bash
npm test
```
