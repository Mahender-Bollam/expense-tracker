# Expense-Tracker

---
### Description
- It is a simple expense tracker 

### Features
- It has a Edit functionality, if user can add daily expenses and also they can edit their expenses.

### TechStack

- node.js
- React
- Typescript

### Installation and SetUp
clone: 

- After clone the repository user can navigate to their environment and install the given command.
    `npm install`
- After install the packages run the application using give command.
    `npm start`

- After that the navigate the browser and open the given port.
    localhost:3000
