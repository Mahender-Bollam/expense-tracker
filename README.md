## Description

- A UI react application of **Expense Tracker** built using **TypeScript**, enabling users to add, update or delete expenses. 
---

## Features
**Add Expense:**
- Add feature , adds the new expense to the list with details;
  - Description.
  - Amount
  - Category
  - Date

**Edit Expense:**
- Edit expense, fixed the update expense functionality.

**Delete Expense:**
- Delete expense with alert message when user clicks on delete icon.

**Separated Components:**
- Separated the componentd,
  - ExpenseForm
  - Expenselist
  - ExpenseTracker
  - Modal

**Testing:**
- Implemented testing to the react application.

**Integration**
- Integrated frontend and backend using axios
- Get expense
- Add expense
- Update expense
- Delete expense

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Umamaheswari-gude/expense-tracker.git
cd expense-tracker
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the application 
```bash
npm start
```
- The app will be available at `http://localhost:4009`
---

### 4. Run the tests
```bash
npm test
```
