##  How to Get Started:

You’ll need [Node.js](https://nodejs.org/) installed to run the app.

### Steps:

1. Clone this project to your computer:
   ```
   git clone https://github.com/Mahender-Bollam/expense-tracker.git
   ```
2. Open the folder:
   ```
   cd expense-tracker
   ```
3. Install dependencies:
   ```
   npm install
   ```

4. Run the app:
   ```
   npm start
   ```
   
4. Run the tests with coverage:
   ```
   npm test -- --coverage --WatchAll
   ```      

You’ll see results for addition and subtraction printed in the terminal.
