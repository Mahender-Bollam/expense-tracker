## Expense Tracker Application

-  This application main goal is `Manage our daily expenses efficiently` and it displays our expenses which makes easy to know where we actually spends.

## Table of content

## Features
- Add new expense 
   - It add new expense to the tracker with `description`,`amount` ,`category` and `date`.

## Installation steps :

1) Clone the repository

   ``` git clone https://github.com/Mahender-Bollam/expense-tracker.git ```
2) Go to project folder 

   ``` cd expense-tracker```
3) Install dependencies

   ```npm install```
