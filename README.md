## Expense Trackor

It is an expense tracor application which has a functionalities of adding an expense , deleting an expense and editing an existing expense .

## Features

- **Adding an Expense**:It Opens a model after clicking the add expense button , then user is able to add an expense to the expenses , validations also performed to maintain clear data.
- **Removing an expense** : Remove an expense from expenses also performed and user is able to remove an expense from the expenses.

- **Edit functionality** : User is able to perform edit on their existing expense in the expenses list .

- **Integrating frontend with backend** : Integrated frontend with backend using firebase for database and axios for API calls.
## How to run 
### Installation

To get started with Book mart, clone the repository and install the necessary dependencies:

```bash
git clone git@github.com:Mahender-Bollam/expense-tracker.git
cd expense-tracker
```
### Install dependencies
```bash
npm install
```

### Run application
```bash
npm start
```

### To test the application
```bash
npm test
```
